# Portfolio Yofan Refki

Portfolio PHP native untuk XAMPP.

## Menjalankan
1. Pastikan Apache dan MySQL aktif di XAMPP.
2. Buka `http://localhost/portofolio%20kerja/`.
3. Import `database.sql` ke phpMyAdmin bila ingin membuat database secara manual. Endpoint komentar juga akan membuat tabel `comments` otomatis jika database `portofolio` sudah tersedia.

## Konfigurasi MySQL
Default di `config/database.php`: host `127.0.0.1`, database `portofolio`, user `root`, password kosong. Sesuaikan password bila MySQL lokal Anda memakai password.
